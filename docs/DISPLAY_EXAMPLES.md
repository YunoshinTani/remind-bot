# Discord表示サンプル

[READMEへ戻る](../README.md) · [ディレクトリ構成](STRUCTURE.md)

氏名・番号・日付・時刻・場所はすべて説明用の架空の例です。実際のDiscordメッセージへのリンクは公開していません。導入先の詳細が必要な場合は、開発者へDiscordのDMでお問い合わせください。

**/next**

```markdown
## あなたの日誌当番の予定
日付：**2026/10/19 (月)**
担当：**1番 青空太郎、2番 星空花子**
```

**/today**

```markdown
## 今日の日誌当番
日付：**2026/10/15 (木)**
担当：**1番 青空太郎、2番 星空花子**
回収状況：**❌未回収**
```

**朝の通知**

```markdown
## 日誌の回収をお願いします
日付：**2026/10/15 (木)**
担当：**@01-青空太郎（1番）、@02-星空花子（2番）**
サンプル保管場所から日誌を回収してください。
回収できたら「回収しました」を押してください。
```

**昼の通知**

```markdown
@everyone
## 日誌がまだ回収されていません
日付：**2026/10/15 (木)**
担当：**1番 青空太郎、2番 星空花子**
回収期限：**12:50**（昼休み終了）
期限までに日誌を回収してください。
すでに回収している場合は「回収しました」を押してください。
```

**回収後の通知**

```markdown
## 日誌の回収をお願いします
日付：**2026/10/15 (木)**
担当：**@01-青空太郎（1番）、@02-星空花子（2番）**
サンプル保管場所から日誌を回収してください。
回収できたら「回収しました」を押してください。
回収状況：**✅回収済み**
記録時刻：**10:00**
記録者：@01-青空太郎
```

記録者は最初に回収ボタンを押した人です。代理回収にも対応し、表示更新でメンション通知を送りません。

**回収ボタンの返信**

```markdown
✅ **回収を記録しました**
ありがとうございます！
```

**照合できなかった場合**

```markdown
⚠️ **名簿の照合ができませんでした**
あなたのDiscordアカウントを在籍中の名簿に照合できませんでした。
表示名が「番号-氏名」になっているか確認し、管理者に連絡してください。
```
